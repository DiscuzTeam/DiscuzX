### Introduction
Discuz! X5 Official International Edition Git Repository - https://github.com/DiscuzTeam/DiscuzX

### About X5
- Starting from X5.0, Discuz! no longer includes UCenter server by default. If you need multi-site deployment, please download [UCenter](https://gitee.com/Discuz/UCenter) separately
- Starting from X5.0, the installer includes an upgrade program by default. Please upgrade to X3.5 version first
- Starting from X5.0, the installer includes a toolbox program by default. Please rename install/index.php file to enable it
- Starting from X5.0, PHP 7 environment will no longer be supported. Please prepare PHP 8 environment before installation or upgrade
- X5 is compatible with X3.5 applications. However, please consult the application developer regarding PHP 8 compatibility
- We welcome active PRs from the community. Discuz! has been open source since 2001 and relies on everyone's support
